## Swift / Apple エコシステム

- **SE-0513 第2レビュー開始 — 実行中バイナリのパス取得 API（〜6/30）**: `ProcessInfo.processInfo.executableURL` の代替として全プラットフォーム統一 API を提案。macOS・Linux・Windows で一貫した `CurrentProcess.executableURL` を標準化。CLI ツール・デーモン・Server-Side Swift 開発者に実務影響あり。第1レビュー時の命名議論を踏まえた修正版で再審査中
  - [https://forums.swift.org/t/second-review-se-0513-api-to-get-the-path-to-the-current-executable/87445](https://forums.swift.org/t/second-review-se-0513-api-to-get-the-path-to-the-current-executable/87445)

- **ST-0025 タグベーステスト実行フィルタリングのレビュー（〜6/26）**: Swift Testing フレームワークに `@Tag` ベースのテスト選択実行機能を追加する提案。`swift test --filter tag:slow` のような CI 最適化が可能になる予定で、xcodebuild のテストプラン連携も視野に。swift-testing を採用済みのプロジェクトはフィードバックを推奨
  - [https://forums.swift.org/t/review-st-0025-tag-based-test-execution-filtering/87320](https://forums.swift.org/t/review-st-0025-tag-based-test-execution-filtering/87320)

- **SE-0533（非同期関数の同期オーバーロード生成マクロ）レビュー終了 — LSG 決定待ち**: `@SyncOverload` マクロで `async` 関数から自動的に同期版を生成する提案のレビューが 6/15 に終了。既存の Dispatch ベース同期ラッパーを手書きしているコードベースへの恩恵が大きく、採択されれば移行パスの設計が課題になる
  - [https://forums.swift.org/t/se-0533-generating-synchronous-overloads-of-async-functions-with-a-macro/87019](https://forums.swift.org/t/se-0533-generating-synchronous-overloads-of-async-functions-with-a-macro/87019)
