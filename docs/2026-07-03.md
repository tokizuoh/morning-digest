## AI（Anthropic / OpenAI）

- **Claude Sonnet 5 が一般提供開始、Free/Proのデフォルトモデルに（6/30）**：Anthropic史上最もエージェント的なSonnetと位置付けられ、ネイティブ1Mトークンコンテキストを標準搭載。Claude Code・API・Bedrock・Vertex AI・Microsoft Foundry経由で利用可能。価格は$2/$10 per Mtok（8/31までの導入価格）で、Opus 4.8に迫るエージェント性能を謳う。Claude Codeを日常的に使うSwift/iOSエンジニアはモデル切り替えとコンテキスト長拡大の影響を要確認。
  - [https://www.anthropic.com/news/claude-sonnet-5](https://www.anthropic.com/news/claude-sonnet-5)

- **Claude Code v2.1.198、Claude in Chromeが正式GA（7/1）**：バックグラウンドエージェントの通知改善、`/dataviz`スキル追加に加え、サブエージェントやコンテキスト圧縮時にextended thinking設定を引き継ぐよう修正。バックグラウンドエージェントはworktreeでの作業完了時に確認待ちせず自動でcommit/push/draft PR作成する挙動に変更されており、CI連携している開発者は動作変化に注意。
  - [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Codex、Responses WebSocketのペイロード全文がトレースログに残る不具合を修正（7/1・rust-v0.142.5）**：地味だがWebSocketモードでCodex/Responses APIを使う開発者にとってはログ肥大化・機密情報混入リスクを下げる修正。API経由でOpenAIモデルを組み込むiOSバックエンドの運用者は関連バージョンへの更新を推奨。
  - [https://developers.openai.com/codex/changelog](https://developers.openai.com/codex/changelog)
