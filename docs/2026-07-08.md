## AI（Anthropic / OpenAI）

- **Claude Cowork、iPhone/iPad/Android/claude.aiへ展開開始（7/7）**：これまでmacOS限定だったタスク委任機能「Cowork」が、iPhone/iPad/Android版アプリとclaude.ai（Maxプランからベータ提供）へ拡大した。セッションとファイルは端末をまたいで永続化され、PCで開始したタスクの進捗をスマホで確認したり、端末がオフラインでもクラウド側でClaudeが作業を継続し、許可が必要な場面だけ通知する設計になっている。長時間タスクを外出先から見守りたいエンジニアに直接関係する。
  - [https://claude.com/blog/cowork-web-mobile](https://claude.com/blog/cowork-web-mobile)

- **Claude Codeの「モデル」と「effort」の使い分けガイドを公開（7/7）**：`effort`設定はモデル選択とは独立して、Claudeが着手前に読むファイル数・呼び出すツール数・自律的に進める手数を左右すると説明。Claudeがテストやファイルを飛ばすなど「詰めが甘い」ときはeffortを上げ、真剣に取り組んでいるのに間違え続ける場合はモデルのアップグレードが適切という判断基準を明示した。Claude Codeの挙動をチューニングする開発者に実務的な指針となる。
  - [https://claude.com/blog/claude-model-and-effort-level-in-claude-code](https://claude.com/blog/claude-model-and-effort-level-in-claude-code)

- **OpenAI、低遅延音声向けの新Realtime APIモデル gpt-realtime-2.1 / gpt-realtime-2.1-miniを公開（7/6）**：キャッシュ改善によりp95レイテンシを約25%短縮し、英数字認識や無音・割り込み処理の精度も向上した。上位モデルはreasoning effort設定やツール呼び出しに対応し、mini版は低コストな蒸留版として提供される。WebRTC/WebSocket/SIP経由で音声エージェントを組むiOSアプリ開発者に関係が深い。
  - [https://developers.openai.com/api/docs/models/gpt-realtime-2.1](https://developers.openai.com/api/docs/models/gpt-realtime-2.1)

- **Claude Code v2.1.202/v2.1.203がリリース、バックグラウンドセッションの応答停止を修正（7/6〜7/7）**：v2.1.202はOpenTelemetryのワークフロー属性追加やmTLSハンドシェイク失敗の修正、`/review <pr>`の単一パス方式への回帰（マルチエージェントレビューは`/code-review`に移管）を実施。v2.1.203ではログイン期限切れの事前警告を追加し、デーモンの古いトークンが原因でバックグラウンドセッション・サブエージェントが応答しなくなる不具合を修正した。バックグラウンドエージェントを常用する開発者は早めの更新が推奨される。
  - [https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
