## AI（Anthropic / OpenAI）

- **OpenAI、GPT-5.6ファミリー（Sol/Terra/Luna）を一般提供開始（7/9）**：プレビューを経てChatGPT・Codex・APIに展開。1.05Mトークンのコンテキストウィンドウを共通搭載し、価格はSol $5/$30、Terra $2.50/$15、Luna $1/$6（per Mtok）。プロンプトキャッシュも明示的なキャッシュブレークポイントと30分の最小キャッシュ寿命に刷新され、OpenAI APIをバックエンドに組み込むエンジニアはキャッシュ課金ロジックの見直しが必要。
  - [https://openai.com/index/gpt-5-6/](https://openai.com/index/gpt-5-6/)

- **Codex、レガシーモデルIDを7/23付けでハードシャットダウン（継続議論）**：`gpt-5.1-codex`や`gpt-5.2-codex`などconfig.tomlや`--model`フラグに直書きされたモデル文字列は7/23に動作しなくなる。CIのシェルスクリプトやGitHub Actionsでモデル名をハードコードしているパイプラインが最も影響を受けやすく、地味だが見落としがちな破壊的変更。
  - [https://github.com/openai/codex/discussions/17038](https://github.com/openai/codex/discussions/17038)

- **Anthropic、Claude Cowork をモバイル・Web に拡張（7/7）**：これまでデスクトップ専用だったCoworkがクラウド化され、iPhone/iPad/Android/claude.aiから同一セッション・ファイルにアクセス可能に。デバイスがオフラインでもバックグラウンドでタスクを継続実行でき、判断が必要な場面はスマホに通知が届く。Max プランからベータ開始。
  - [https://claude.com/blog/cowork-web-mobile](https://claude.com/blog/cowork-web-mobile)

- **Anthropic、Claude Code と Cowork を政府機関向けに拡大（7/7）**：FedRAMP High認定環境でClaude Code/Cowork Desktopがパブリックベータに。行政機関のソフトウェア刷新やデスクトップ上のファイル操作を想定しており、監査ログや支出管理などガバナンス機能も追加。
  - [https://claude.com/blog/bringing-claude-code-and-claude-cowork-to-government](https://claude.com/blog/bringing-claude-code-and-claude-cowork-to-government)
