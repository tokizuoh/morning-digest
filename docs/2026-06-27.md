## Swift / Apple エコシステム

- **SE-0527 UniqueArray「修正付き採択」決定**：非コピー可能要素を格納できる可変長配列 UniqueArray が Swift Standard Library へ採択（RigidArray は見送り）。Containers モジュール新設は見送られ Swift モジュール直下に収録。setCapacity(_:) でキャパシティを明示変更できる設計。Atomic・Mutex に続く noncopyable 対応コンテナの第一弾として注目。
  - [https://forums.swift.org/t/accepted-with-modifications-se-0527-uniquearray/87282](https://forums.swift.org/t/accepted-with-modifications-se-0527-uniquearray/87282)

- **ST-0025「タグベーステスト実行フィルタリング」レビュー期間終了（6/26）、採否判定待ち**：swift-testing のテストに任意タグを付与し `--filter-tags` で選択的実行できる提案。CI でスモークテストと全テストを柔軟に分離できる仕組みで実務ニーズが高い。XCTest の `--only-testing` 相当を Swift Testing でも実現するための基盤。判定結果に注目。
  - [https://forums.swift.org/t/review-st-0025-tag-based-test-execution-filtering/87320](https://forums.swift.org/t/review-st-0025-tag-based-test-execution-filtering/87320)

- **SE-0519「Ref / MutableRef」—安全な第一級参照型のピッチが活発化**：値型への共有・排他参照を Ref<T> / MutableRef<T> として明示的に扱えるようにする提案。ローカル変数・struct メンバ・ジェネリック型引数として使用可能で、ポインタなしに参照セマンティクスを表現できる。WWDC26 で先行デモ済みで次のレビューフェーズ移行が期待される。
  - [https://www.swift.org/blog/whats-new-in-swift-may-2026/](https://www.swift.org/blog/whats-new-in-swift-may-2026/)
