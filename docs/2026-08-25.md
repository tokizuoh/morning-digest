## Swift / Apple エコシステム

- **SE-0539「イニシャライザでのマクロへのselfアクセス許可」がリビジョンのため差し戻し**：8月16日にレビュー終了後、Language Steering Groupが「解決すべき課題だが現状案は不十分」として差し戻しを決定し、8月24日にPRマージで反映された。`@Observable`のようにストアドプロパティをcomputedプロパティへ変換するマクロがinitializer内でselfにアクセスできない制約の解消を狙ったもので、マクロ作者は改訂版の行方に注目したい。
  - [https://forums.swift.org/t/returned-for-revision-se-0539-enable-macros-to-grant-self-access-for-property-initializers/89155](https://forums.swift.org/t/returned-for-revision-se-0539-enable-macros-to-grant-self-access-for-property-initializers/89155)

- **ST-0025「タグベースのテスト実行フィルタリング」がswift-testingに実装完了**：6月に承認済みだった提案が8月24日付で「Implemented」ステータスに更新された。`swift test --filter tag:xxx` / `--skip tag:xxx`のように名前ベースのregexフィルタとタグベースの絞り込みを組み合わせられるようになり、UIテストと単体テストの使い分けなど大規模プロジェクトのテスト運用に直接効いてくる。
  - [https://github.com/swiftlang/swift-evolution/pull/3438](https://github.com/swiftlang/swift-evolution/pull/3438)

- **SE-0542「Package Manager Condition Plugins」のレビューが8月21日で終了**：SwiftPMのtarget宣言の`plugins`パラメータに、他のSwiftPM宣言と同様platform/trait条件を付与できるようにする提案。プラグイン適用条件を細分化でき、CI/ビルド設定を複雑に分岐させているパッケージに地味に効くビルド構成機能で、コアチームの決定発表待ちの段階。
  - [https://forums.swift.org/t/se-0542-package-manager-condition-plugins/88820](https://forums.swift.org/t/se-0542-package-manager-condition-plugins/88820)

- **Unicode.Scalar.PropertiesへbidiClassを追加するピッチが公開**：現状Unicode標準のBidi_Class（双方向アルゴリズムの分類）がSwift標準ライブラリから取得できず、言語処理系や行レイアウトライブラリはICUへのブリッジコードが必要という、見落とされがちな穴を埋める提案。実装は先行してswiftlang/swift側にも提出されている。
  - [https://forums.swift.org/t/pitch-add-bidiclass-to-unicode-scalar-properties/89097](https://forums.swift.org/t/pitch-add-bidiclass-to-unicode-scalar-properties/89097)
