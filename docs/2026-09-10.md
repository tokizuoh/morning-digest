# 2026-09-10

OpenAIが数学の未解決問題ナビエ・ストークス方程式の解決を発表し研究不正論争が続く一方、Appleは9月9日のイベントで折りたたみ式「iPhone Duo」とiOS 27などのRC版を実際にリリースし秋の新体制が本格始動。Anthropicでは研究者がAI安全性への懸念から公然と退社を表明するなど、AI業界の技術的躍進と内部の緊張が同時に表面化した一日。

## AI（Anthropic / OpenAI / Google）

- **OpenAI、AIエージェント群がミレニアム懸賞問題「ナビエ・ストークス方程式」を解決したと発表**：OpenAIは9月8日、社内の未公開モデル（GPT-6 Astraより高性能）を用いたAIエージェント群が、約90年間未解決だったナビエ・ストークス方程式の有限時間発散（滑らかな3次元流体運動が有限時間で破綻しうること）を証明したと発表した。最大1万体のエージェントを並列投入し約88時間で結論に到達、Lean形式検証にはGPT-6 Astraでさらに17時間を要し、過程で270万件のメッセージと約1300億出力トークンを消費したという。165ページの証明とLean形式検証済みコードをApache-2.0ライセンスで公開しており、AIが数学研究のフロンティアに実際に到達した象徴的な事例として、Codex等のエージェント型ツールを使う開発者にとっても長時間自律タスクの実力を測る参考事例になる。
  - [https://openai.com/index/navier-stokes-solution/](https://openai.com/index/navier-stokes-solution/)

- **Anthropicの研究者、「AI企業は人類の命を賭けている」と警告し退社を表明**：Anthropicで3年間研究に携わったJacob Coxon氏は9月9日、Anthropicと競合他社がモデル性能競争を安全性より優先していると批判し、公然と退社を表明した。Anthropicのアラインメント科学リード Evan Hubinger氏も「AIが全人類を殺しうると本気で考えている」「best を尽くしているが超知能のアラインメントを解決する計画はまだない」とX上で一部主張を認める投稿をしており、フロンティアAI企業内部の安全性への危機感が公になった珍しいケース。
  - [https://fortune.com/2026/09/09/anthropic-researcher-resigns-warn-ai-companies-gambling-with-lives/](https://fortune.com/2026/09/09/anthropic-researcher-resigns-warn-ai-companies-gambling-with-lives/)

- **Google、フィンランドに2年で130億ユーロを投資しAI向けに原発電力を初調達**：GoogleはフィンランドのFortum社と9月9日、原子力発電購入契約を締結したと発表した。ロヴィーサ原発の発電容量を2028年から段階的に購入し2030〜2049年には最大50%を確保、既存のハミナ・データセンターの拡張とカヤーニ・ヴァーラ・ムホスへの新設データセンター建設に充てる。Googleにとって米国外初の原発電力契約であり、AI計算需要を支える電力調達がハードウェア以外の制約要因になりつつあることを示す事例。
