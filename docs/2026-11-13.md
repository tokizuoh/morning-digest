## Swift / Apple エコシステム

- **Pitch：`swift package audit` で依存パッケージの既知の脆弱性を監査（#3585）**：解決済みの依存を osv.dev などのセキュリティアドバイザリと照合する `swift package audit` と、修正版へ上げる `audit fix` を SwiftPM に追加する提案。パッケージレジストリがアドバイザリを配信するための新しいエンドポイントも含む。
  - [https://github.com/swiftlang/swift-evolution/pull/3585](https://github.com/swiftlang/swift-evolution/pull/3585)
- **SE-0566：結果ビルダー属性のジェネリック引数を推論（#3062 / #3587）**：`@ArrayBuilder` や `@DictionaryBuilder<String, _>` のように、ジェネリックな結果ビルダーの型引数を省略したりプレースホルダーで書いたりできるようにする提案。11/12 に提案文書がマージされ、レビュー開始の PR も出た。独自 DSL を作る際の記述が楽になる。
  - [https://github.com/swiftlang/swift-evolution/pull/3062](https://github.com/swiftlang/swift-evolution/pull/3062)
- **SE-0565：パッケージのプロダクトを非推奨にできるように（#3401）**：`Package.swift` のプロダクトに `deprecated: .unsupported(message:replacement:)` を指定でき、利用者にはビルド時に警告と移行先が表示される。CI で検出できるサブコマンドも追加される。ライブラリを公開している人は、プロダクトの名前変更や分割をしやすくなる。
  - [https://github.com/swiftlang/swift-evolution/pull/3401](https://github.com/swiftlang/swift-evolution/pull/3401)
