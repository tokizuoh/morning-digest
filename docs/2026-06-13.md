  - [https://forums.swift.org/t/second-review-se-0516-iterable/87106](https://forums.swift.org/t/second-review-se-0516-iterable/87106)

  - [https://github.com/apple/container](https://github.com/apple/container)

- **Swift.org Networking Workgroup 発足（6/4）**: ネットワーキングライブラリ・プロトコル・API の進化を統括するワークグループが正式設立。URLSession の後継を見据えた API 設計の方向性に注目
