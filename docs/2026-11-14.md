## Swift / Apple エコシステム

- **SE-0566 の推論方法を見直し（#3590）**：結果ビルダーの省略したジェネリック引数を、本体を型チェックして決めるのではなく、宣言の戻り値の型から推論する方式に改めた。型チェックが速くなり、ビルダーの呼び出しすべてで同じ型が使われる。推論できない場合や曖昧な場合の診断も追加。さらに `.swiftinterface` の利用側に新しいコンパイラは要らず、導入による影響はないと明記された。
  - [https://github.com/swiftlang/swift-evolution/pull/3590](https://github.com/swiftlang/swift-evolution/pull/3590)
- **SE-0554「デプロイメントターゲットによる条件付きコンパイル」は却下**：`#if deploymentTargetAtLeast(iOS 18, *)` のように、最低対応 OS バージョンに応じて import や型エイリアス、保存プロパティの型をコンパイル時に切り替える提案だった。却下されたため、当面は今まで通り `#available` と `@available` で分岐することになる。
  - [https://forums.swift.org/t/rejected-se-0554-deployment-target-conditional-compilation/90589](https://forums.swift.org/t/rejected-se-0554-deployment-target-conditional-compilation/90589)
- **「Swift Next」の表記が「Swift 6.5」に（#3579 / #3580）**：Swift 6.5 のリリース日程が発表されたのに合わせて、swift-evolution の表記が改められた。SE-0552（`Float.pi` などを最近接値に丸める変更）と SE-0551 も、Swift 6.5 で実装済みになった。`.pi` を使った計算結果がわずかに変わる可能性があるため、数値を比べるテストは確認しておくとよい。
  - [https://github.com/swiftlang/swift-evolution/pull/3580](https://github.com/swiftlang/swift-evolution/pull/3580)
