## AI（Anthropic / OpenAI）

- **Claude Code v2.1.200、デフォルトの権限モードを「Manual」に変更（7/3）**：CLI・VS Code・JetBrains拡張のすべてで、これまでの既定モードに代わり「Manual」モードが標準になった。あわせて`AskUserQuestion`ダイアログもデフォルトで自動継続しなくなり、ユーザーの明示的な承認をより厳格に求める設計に変わった。何もせずアップデートすると確認プロンプトが急増するため、自動承認運用に慣れたチームは`/config`での再設定が必要になる地味だが影響の大きい変更。
  - [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Codex Remoteが正式GAに、iPhoneからエージェントの作業を承認可能に**：ChatGPTモバイルアプリから、接続済みのMac/Windowsホスト上でCodexセッションを開始・継続でき、進捗確認とアクション承認をスマートフォン上で行えるようになった。長時間のエージェントタスクを外出先から見守りたいiOSエンジニアにとって、モバイル起点のエージェント運用という新しい選択肢になる。
  - [https://developers.openai.com/codex/changelog](https://developers.openai.com/codex/changelog)

- **Claude Agent SDK、`ClaudeCodeOptions`を`ClaudeAgentOptions`に改称しSessionStore APIを追加**：Python/TypeScript両SDKで設定オブジェクトの名称が変更されたほか、セッション履歴の永続化を担う`SessionStore`プロトコル（append/load/list_sessions/delete/list_subkeysの5メソッド）とそのインメモリ参照実装が追加された。TypeScript版には`getSessionMessages()`によるページネーション付き履歴取得も加わっている。Agent SDK上に独自のXcode連携・CI自動化ツールを構築しているチームは名称変更への追従が必要。
  - [https://github.com/anthropics/claude-agent-sdk-python/blob/main/CHANGELOG.md](https://github.com/anthropics/claude-agent-sdk-python/blob/main/CHANGELOG.md)

## Swift / Apple エコシステム

- **SE-0534「ビルドメタデータ付きバージョン識別子のオプトイン厳密一致」がレビュー中、締切は本日7/6**：SemVerの仕様上、ビルドメタデータ（`1.0.0+debug`の`+debug`部分）はバージョンの優先順位比較で無視されるべきとされる一方、SwiftPMは優先順位が同じで末尾のビルドメタデータだけが異なる複数タグがある場合に特定の1タグへ確実にピン留めできない問題がある。本提案はオプトインの厳密一致モードを追加してこれを解消する。依存関係をタグ固定して再現可能ビルドを行いたいチームは、意見を出す最後のタイミング。
  - [https://forums.swift.org/t/review-se-0534-opt-in-exact-matching-for-version-identifiers-with-build-metadata/87815](https://forums.swift.org/t/review-se-0534-opt-in-exact-matching-for-version-identifiers-with-build-metadata/87815)

- **SE-0532「非コピー可能Optionalの改良・一般化」、API名を`borrow()/mutate()/insert()`から`.ref/.mutableRef/.put()`に変更してレビュー継続中（6/30改定）**：`map`・`flatMap`・`unsafelyUnwrapped`を非コピー可能な内包型に対応させ、`if let`で消費せずにOptionalの非コピー可能な中身を参照・変更できるようにする提案。レビュー中に主要APIの命名が変わったため、非コピー可能型×Optionalを試している開発者は古い`borrow()/mutate()/insert()`の名前でコードを書かないよう注意が必要。
  - [https://github.com/swiftlang/swift-evolution/pull/3342](https://github.com/swiftlang/swift-evolution/pull/3342)

- **SE-0505「エグゼキュータへの遅延エンキュー」、キャンセル対応を追加する形で再改定（7/1）**：1月に一度差し戻されたこの提案が、遅延エンキューされたタスクを適切にキャンセルできるよう修正され、対応する実装も既に存在するという。カスタムエグゼキュータを実装してタスクキャンセルと組み合わせたい開発者は、次のレビューラウンドに向けて動向を追う価値がある。
  - [https://github.com/swiftlang/swift-evolution/pull/3317](https://github.com/swiftlang/swift-evolution/pull/3317)
