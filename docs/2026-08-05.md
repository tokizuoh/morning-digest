## Swift / Apple エコシステム

- **SE-0536「Package Registry Search」が修正付きで受理、`swift package-registry search`が正式導入へ（8/3）**：エコシステム運営委員会（ESG）が7/10〜7/24のレビューを経てレジストリへの検索エンドポイント追加と対応するSwiftPMサブコマンドを修正付きで受理。これまでパッケージレジストリの利用には正確なパッケージ識別子（`scope.name`）を事前に知っている必要があったが、名前・作者などによる発見的検索が標準化される。SwiftPMを日常的に使う開発者に直結する仕上げの一歩。
  - [https://forums.swift.org/t/accepted-with-modifications-se-0536-package-registry-search/88746](https://forums.swift.org/t/accepted-with-modifications-se-0536-package-registry-search/88746)

- **SE-0540「Default Package Settings」、本日レビュー開始（〜8/17）**：Package.swift内で同じ`swiftSettings`を全ターゲットに手作業でコピーする定型作業を解消するため、パッケージ全体に適用されるデフォルト設定を宣言できる仕組みを提案。コンパイラフラグや実験的機能の有効化をターゲットごとに繰り返し記述してきた中〜大規模SwiftPMパッケージのメンテナに直結する提案。
  - [https://forums.swift.org/t/se-0540-default-package-settings/88748](https://forums.swift.org/t/se-0540-default-package-settings/88748)

- **SE-0539「マクロによるプロパティ初期化子内でのselfアクセス許可」、レビュー継続中（8/2〜8/16）**：`@attached(accessor, initialization: selfAvailable, ...)`という新オプションを追加し、アクセサマクロで生成した初期化式でも`lazy var`同様に`self`や他インスタンスメンバへアクセスできるようにする提案。独自の遅延初期化・プロパティラッパー系マクロを自作するエンジニアに直結する変更で、レビュー期間は8/16まで続く。
  - [https://forums.swift.org/t/se-0539-enable-macros-to-grant-self-access-for-property-initializers/88713](https://forums.swift.org/t/se-0539-enable-macros-to-grant-self-access-for-property-initializers/88713)
