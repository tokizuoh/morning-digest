## Swift / Apple エコシステム

- **SE-0538「Disconnected」、本日レビュー最終日（7/17〜7/31）**：Region-based Isolation（SE-0414）における「他リージョンと未接続（disconnected）」な非Sendable値を、関数境界の`sending`注釈以外の場所（格納プロパティやジェネリックなキューなど）でも安全に保持できるようにする`Disconnected<Value>`ラッパー型を提案。`init(_:)`・`take()`・`swap(newValue:)`・`withValue(body:)`という`sending`境界のみを許す操作を提供し、無条件で`Sendable`準拠を安全にする。Swift 6モードで非Sendable値を扱う開発者に直結する提案。
  - [https://forums.swift.org/t/se-0538-disconnected/88361](https://forums.swift.org/t/se-0538-disconnected/88361)

- **SE-0526「withDeadline」が修正付きで受理（7/29頃）**：クロックの絶対時刻（Instant）を締切として非同期処理を実行し、超過時にキャンセルする`withDeadline`が、レビュー指摘を受けて`CancellationError.Reason.userRequested`を`.unspecified`に改名する修正付きで受理された。`Task.hasActiveDeadline`/`Task.activeDeadline(for:)`によるクエリAPIや`Task.cancel(reason:)`も追加され、構造化並行処理でタイムアウトを書く開発者に関わる変更。
  - [https://forums.swift.org/t/accepted-with-modifications-se-0526-withdeadline/88645](https://forums.swift.org/t/accepted-with-modifications-se-0526-withdeadline/88645)

- **新設Networking Workgroup、初の公開ミーティング議題を公開（8/3開催、7/30投稿）**：優先事項として、構造化並行処理ベースの統一HTTPクライアント/サーバーAPI設計、IPアドレス・ホスト名・HTTPリクエスト/レスポンスなどライブラリ間で相互運用可能な「currency types」の策定、TLS/HTTP1.1/HTTP2/HTTP3/QUIC/WebSocketsの共有プロトコル実装ガイドを挙げる。DarwinのNetwork frameworkやswift-nio固有の型に代わるクロスプラットフォーム標準の議論が始動した、見落とされがちだが今後影響の大きい動き。
  - [https://forums.swift.org/t/networking-workgroup-public-meeting-monday-august-3-2026-agenda-and-call-for-topics/88623](https://forums.swift.org/t/networking-workgroup-public-meeting-monday-august-3-2026-agenda-and-call-for-topics/88623)

- **[PR] SE-0536「Package Registry Search」、レビューフィードバックを反映した改訂PRを提出（7/31）**：あいまい検索（fuzzy matching）の対象を自由テキストと`name:`/`description:`修飾子のみに限定し`scope:`/`author:`/`pkg:`は決定的マッチングを必須化、ページネーションを「同一セッション内で安定」という規則から決定的な順序付け＋タイブレーカー方式に変更するなど、`swift package search`コマンドの実装に直結する仕様修正。
  - [https://github.com/swiftlang/swift-evolution/pull/3387](https://github.com/swiftlang/swift-evolution/pull/3387)
