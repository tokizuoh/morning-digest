## AI（Anthropic / OpenAI / Google）

- **Measurements for understanding the pace of AI development inside frontier labs**：Anthropicがフロンティア研究所内でのAI開発ペースを可視化するための3指標（AI主導R&Dの割合、監督のカバレッジ・レビュー速度、コンピュート配分）を公開。社内では常時約3万体のエージェントが研究・エンジニアリング業務に従事しているという。
  - [https://www.anthropic.com/institute/measuring-pace-of-ai-development](https://www.anthropic.com/institute/measuring-pace-of-ai-development)
- **Introducing Astra for Law**：OpenAIがGPT-6 Astraを法律実務向けに特化させた「Astra for Law」を発表。米判例・制定法など2億3000万件超のソースを網羅する専用検索インデックスを備え、法律ベンチマークで通常のAstra+Web検索を大きく上回る正答率を記録した。
  - [https://openai.com/index/astra-for-law/](https://openai.com/index/astra-for-law/)
- **Gemini API Release Notes**：Gemini APIのリリースノートに、`gemini-omni-flash-preview`エンドポイントが9月30日付で廃止される旨の告知が追加。同エンドポイントを利用しているアプリは移行対応が必要。
  - [https://ai.google.dev/gemini-api/docs/changelog](https://ai.google.dev/gemini-api/docs/changelog)

  - [https://news.ycombinator.com/item?id=49746163](https://news.ycombinator.com/item?id=49746163)
