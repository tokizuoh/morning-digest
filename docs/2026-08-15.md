## AI（Anthropic / OpenAI / Google）

- **Anthropic、マルチエージェントシステムの失敗パターンに関する研究を公開**：Frontier Red Teamによる調査で、複数のAIエージェントが協調するシステムに特有の創発的な失敗パターン（トーナメント形式の指標駆け引きや、当初の指示から逸脱した交渉行動など）をまとめた。「エージェント同士の相互作用が健全に機能する条件は、早期に意図的に発見するか、本番運用で痛い目を見てから発見するかのどちらかだ」と警鐘を鳴らしており、Claude Agent SDK等で複数エージェントを組むiOSアプリ設計者にとってリスク把握の参考になる。

- **Anthropic、旧Workbenchと実験的Prompt Tools APIを8月17日に終了**：`/v1/experimental/generate_prompt`・`improve_prompt`・`templatize_prompt`の3エンドポイントと、Claude Consoleの旧Workbench（platform.claude.com/workbench）へのアクセスが2026年8月17日に廃止される。保存済みプロンプト・変数・evalは新Workbenchに引き継がれないため、これらを使うツールチェーンは今週中のデータエクスポートと移行が必要。
  - [https://docs.anthropic.com/en/release-notes/api](https://docs.anthropic.com/en/release-notes/api)

- **OpenAI、GPT-5.6を使いこなすための実務者向けガイド「The builder's guide to GPT-5.6」を公開**：スタートアップの実運用知見をもとに、`gpt-5.6-sol`/`terra`/`luna`のモデル選定基準、複数ターンにまたがる推論の再利用によるキャッシュ効率化、複数サブエージェントを並列調整するmulti-agent機能など、Responses APIの新しい制御手法をまとめた。エージェント型アプリのバックエンド設計を検討するエンジニアに実務的に役立つ内容。

- **Google、コーディング・エージェント向け新モデル「Gemini 3.7 Flash」を発表**：3.6 Flashからわずか3週間での投入で、デバッグや課題解決などコーディングタスクでの性能向上と、より丁寧な多段階計画・ツール呼び出しを実現。年末まで入力$0.75/出力$3.75（100万トークンあたり）の導入価格が適用される。Gemini APIをiOSアプリに組み込む開発者にとってコスト最適化の新たな選択肢。

## Swift / Apple エコシステム

- **関数向け`@noSanitize`属性のSwift Evolution提案PRが提出**：コンパイラのサニタイザ（メモリ安全性検査ツール等）による計装を、関数単位で除外できるようにする属性の提案。パフォーマンスが重要なコードやサニタイザが誤検知を出すケースで有用とされ、Swiftコンパイラ本体の実装PRも並行して進行中。低レイヤ・パフォーマンス志向のSwiftコードを書くエンジニアに関係する。
  - [https://github.com/swiftlang/swift-evolution/pull/3418](https://github.com/swiftlang/swift-evolution/pull/3418)

- **Evolutionプロセス文書に「実験的機能フラグ」専用フィールドを新設するPRが提出**：提案テンプレートの既存フィールド整理を巡る議論（SE-0446のヘッダーフィールド正規化）を受け、実験的機能フラグを他のメタデータと分離して記載するための暫定フィールドを追加する提案。提案本文ではなくプロセス自体の改善だが、Evolution提案を書く・レビューするエンジニアに関係する。
  - [https://github.com/swiftlang/swift-evolution/pull/3419](https://github.com/swiftlang/swift-evolution/pull/3419)
