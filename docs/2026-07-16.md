## AI（Anthropic / OpenAI）

- **Claude Code 2.1.211、Auto ModeがフックのBash承認判定を上書きする不具合を修正**：サンドボックス外で実行するBashコマンドに対し、PreToolUseフックが`ask`（要承認）と判定していたにもかかわらずAuto Modeがそれを上書きして自動実行してしまう不具合が修正された。他にも`--forward-subagent-text`フラグの追加、スリープ復帰後に並行セッションが同時ログアウトする不具合、プラグイン提供MCPサーバーがアイドルWebセッション復帰後に再接続しない不具合などを修正。フックでガードレールを組んでいるチームは早めの更新を。
  - [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Anthropic、メモリストアAPIの`agent-memory-2026-07-22`ベータヘッダーが7/22に強制切替へ**：Managed Agentsのメモリ一覧取得（`GET /v1/memory_stores/{id}/memories`）の挙動を変更するベータヘッダーで、結果はサーバー定義の安定順で返るようになり`order_by`/`order`は無視、`depth`は0か1のみ許容、`path_prefix`は末尾`/`必須でパスセグメント単位一致に変わる。7/2以降SDKは新ヘッダーを自動送信済みだが、7/22には旧ヘッダー`managed-agents-2026-04-01`側の挙動も新仕様に統一される。旧ページカーソルは新ヘッダー下では無効になるため、Managed AgentsのメモリAPIを直接叩いているコードは要確認。
  - [https://platform.claude.com/docs/en/api/beta-headers#endpoint-specific-headers](https://platform.claude.com/docs/en/api/beta-headers#endpoint-specific-headers)

- **OpenAI Codex Remoteが正式GA、ChatGPTモバイルアプリからホストへのリモート承認が可能に**：接続済みのMac/Windowsホスト上でCodexのスレッド開始・追質問・コマンド承認/拒否・diffやテスト結果の確認をスマホから行えるようになった。各デバイスとホスト間は認証付きQRペアリングで1対1に紐付けられ、6/8以降未使用の旧接続は再ペアリングが必要。タスク完了・入力待ちでプッシュ通知が飛ぶため、長時間タスクをポーリングせず外出先から扱えるようになる。
  - [https://developers.openai.com/codex/changelog](https://developers.openai.com/codex/changelog)
